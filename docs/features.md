# Viva Editor 功能说明

Viva Editor 首先面向 Windows 上的代码、配置和本地文档编辑。下表按当前版本的入口和能力汇总。

| 模块 | 已实现 |
| --- | --- |
| 文本和语法 | UTF-8、UTF-8 BOM、LF/CRLF、无后缀文件、中文输入、选区、查找、撤销重做、自动折行、文件类型手选 |
| 配置与代码高亮 | JSON、XML、YAML、Properties、INI、TOML、ENV、HTML、Markdown、JSON Lines、CSV、TSV、日志及常见编程语言 |
| 标签和项目 | 多窗口、多个项目根目录、文件树、拖动标签和分组、折叠组、固定保护、批量关闭、关闭后零标签页、最近文件和资源管理器入口 |
| 查找 | 当前文档或全部已打开文档、普通文本与 Go 正则、按文件分组的底部结果、命中定位、复制结果 |
| JSON | 格式化、压缩、键排序、折叠摘要、Form-Data 文本、XML、转义和 Unicode 转换、双栏差异、逐项合并 |
| Markdown | 分屏预览、标题大纲、定位和同步滚动 |
| HTML | 源码编辑、系统浏览器打开、内嵌分屏、执行页面脚本、相对资源解析、未保存内容刷新 |
| Excel | `.xlsx` 多工作表浏览、单元格内容和公式编辑、字体和颜色等常用格式、保存及另存为 |
| Word | `.docx` 正文、段落、列表、表格和图片的常用编辑、保存及另存为 |
| PDF、XMind、图片 | PDF 翻页、缩放、查找和原件另存。XMind 画布与分支查看。PNG、JPEG、GIF、BMP、WebP、TIFF 查看和缩放 |
| 主题和恢复 | 每个窗口的明暗主题、Excel 编辑配色、Word/PDF 阅读配色、还原项目与标签、定期保存草稿、最近打开文件 |
| AI 助手 | API 和命令行服务商、模型和思考水平选择、问答、草稿、可审阅修改、附件、对话记录 |
| 工作区工具 | Git 状态、暂存、提交、获取、拉取、推送和本机 PowerShell 会话 |

## 数据和文件行为

- 标签拥有各自的光标、选区、撤销记录和预览设置。再次打开相同路径会定位到已有标签。
- JSON 工具保留原始数字精度，格式化和压缩可保留重复键。结构对比需要能唯一定位键，重复键会提示错误。
- 本地 HTML 预览使用原文件位置解析相对 CSS、JavaScript 和图片。依赖服务器的页面可通过其自身项目服务运行。
- PDF、图片和 XMind 属于只读查看。Word 和 PDF 的深色纸张是显示配色，Word 保存和 PDF 原件导出保留文件颜色。
- Office 与文本编辑器分别维护保存状态。文本跨标签查找覆盖可编辑的文本源文件。
- AI 对话使用用户在该次请求中选择的服务商和上下文，编辑器依据用户审阅结果应用修改。

## 当前范围

纯文本入口支持 UTF-8。GB18030 和 UTF-16 转码、正文替换与整个目录的全文搜索尚未接入。Excel 的工作表增删和移动、行列结构操作、数据透视及图表编辑在当前范围之外。Word 复杂域和精确分页以原有 Office 排版为准。GIF 查看首帧，TIFF 查看第一页。
