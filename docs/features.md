# EditorX 功能说明

EditorX 面向 Windows 上的多格式文件查看与编辑，提供文本编辑、结构化数据处理和常用文档预览。

| 模块 | 已实现 |
| --- | --- |
| 文本和语法 | UTF-8、UTF-8 BOM、LF/CRLF、无后缀文件、中文输入、选区、查找、撤销重做、自动折行、文件类型手选 |
| 语法高亮 | JSON、XML、YAML、Properties、INI、TOML、ENV、HTML、Markdown、JSON Lines、CSV、TSV、日志及常见编程语言 |
| 标签和项目 | 多窗口、拖入文件打开、资源管理器打开方式、多个项目根目录、文件树、拖动标签和分组、双击重命名、折叠组、固定保护、批量关闭、关闭后零标签页、最近文件和资源管理器入口 |
| 查找与替换 | 当前文件或全部已打开的可编辑文本标签、单项与全部替换、多行文本、转义字符、Go 正则和分组引用、替换撤销、按文件分组的搜索结果 |
| JSON | 双栏同步编辑、自动格式化与折行、可取消的转换预览、压缩、键排序、折叠摘要、Form-Data 文本、XML、嵌套去转义和 Unicode 转换、双栏差异、逐项合并 |
| Markdown | 分屏预览、标题大纲、定位和同步滚动 |
| HTML | 源码编辑、系统浏览器打开、内嵌分屏、执行页面脚本、相对资源解析、未保存内容刷新 |
| Excel | `.xlsx` 多工作表浏览、单元格内容和公式编辑、字体和颜色等常用格式、保存及另存为 |
| Word | 公开版提供系统关联程序打开入口。带 Word 组件的本地构建支持 `.docx` 常用编辑、分级标题与跳转、保存及另存为 |
| PDF、XMind、图片 | Word 和 PDF 显示文件名并支持缩放。PDF 支持书签或已标记标题的列表与跳转、翻页、查找和原件另存。XMind 画布与分支查看。PNG、JPEG、GIF、BMP、WebP、TIFF 查看和缩放 |
| 系统托盘 | 点击图标恢复窗口，右键打开设置或退出，独立设置托盘图标和关闭行为，重复启动唤起已有窗口 |
| 设置 | 固定齿轮打开和关闭设置、设置搜索与编辑器实时预览，外观、编辑器和 AI 配置自动保存，支持会话备份、快捷键查看和版本更新 |
| 主题和恢复 | 深色、浅色与跟随 Windows 应用模式、Excel 编辑配色、Word/PDF 阅读配色、还原项目与标签、定期保存草稿、最近打开文件 |
| 可选的 AI 助手 | API 和命令行服务商、模型和思考水平选择、问答、草稿、可审阅修改、附件、对话记录 |
| 可选的文件夹工具 | Git 状态、暂存、提交、获取、拉取、推送和本机 PowerShell 会话 |

## 数据和文件行为

- 标签拥有各自的光标、选区、撤销记录和预览设置。再次打开相同路径会定位到已有标签。
- JSON 工具保留原始数字精度，格式化和压缩可保留重复键。结构对比需要能唯一定位键，重复键会提示错误。
- 本地 HTML 预览使用原文件位置解析相对 CSS、JavaScript 和图片。依赖服务器的页面可通过其自身项目服务运行。
- PDF、图片和 XMind 属于只读查看。Word 和 PDF 的深色纸张是显示配色，Word 保存和 PDF 原件导出保留文件颜色。
- Office 与文本编辑器分别维护保存状态。文本跨标签查找覆盖可编辑的文本源文件。
- AI 对话使用用户在该次请求中选择的服务商和上下文，编辑器依据用户审阅结果应用修改。

## 当前范围

纯文本入口支持 UTF-8。GB18030 和 UTF-16 转码、整个目录的全文搜索尚未接入。Excel 的工作表增删和移动、行列结构操作、数据透视及图表编辑在当前范围之外。Word 复杂域和精确分页以原有 Office 排版为准。GIF 查看首帧，TIFF 查看第一页。
