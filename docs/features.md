## 数据和文件行为

- 标签拥有各自的光标、选区、撤销记录和预览设置。再次打开相同路径会定位到已有标签。
- JSON 工具保留原始数字精度，格式化和压缩可保留重复键。结构对比需要能唯一定位键，重复键会提示错误。
- 本地 HTML 预览使用原文件位置解析相对 CSS、JavaScript 和图片。依赖服务器的页面可通过其自身项目服务运行。
- PDF、图片和 XMind 属于只读查看。Word 和 PDF 的深色纸张是显示配色，Word 保存和 PDF 原件导出保留文件颜色。
- Office 与文本编辑器分别维护保存状态。文本跨标签查找覆盖可编辑的文本源文件。
- AI 对话使用用户在该次请求中选择的服务商和上下文，编辑器依据用户审阅结果应用修改。

## 当前范围

通用对比支持两份文本文件或打开标签（含草稿），每份不超过 32 MiB；左侧为打开对比时的快照，右侧共享主编辑器。文件检测覆盖本地文本，不自动覆盖未保存内容。日志跟随只读取末尾约 128 KiB，不保留日志增长记录；翻页或查找会暂停。宏支持 4 MiB 以内的普通单光标文本，暂不录制跨窗口、文件操作、多光标或大文件完整编辑。自定义工具由用户显式运行，输出可另开标签，不自动替换原文。

快速打开搜索文件名和路径，目录查找搜索磁盘文本内容。目录查找单文件最大 64 MiB，每次最多 5,000 个匹配、100,000 个目录项，跳过或截断会提示；不提供目录批量替换。多光标与编码／换行转换用于普通文本编辑区；大文件分页和完整编辑仍沿用已有单选区及原格式保存流程。多光标最多 2,000 处，列选择在短行末尾停止，不插入虚拟空格。Excel 的工作表增删和移动、行列结构操作、数据透视及图表编辑在当前范围之外。Word 复杂域和精确分页以原有 Office 排版为准。GIF 查看首帧，TIFF 查看第一页。

本地词库匹配已有译文；新句子可选中英离线整句或 AI。离线使用 Argos 模型和 CTranslate2 CPU INT8，完成后退出引擎进程释放内存，模型与运行时均不进入 EXE。安装大小、速度与内存见[实测报告](offline-translation.md)。AI 翻译可独立使用，无需安装词库和离线组件。
