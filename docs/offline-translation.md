# 离线整句翻译与实测

2026-11-24，Windows x64 开发版。已接入 Argos 中英模型和 CTranslate2 CPU INT8 推理，支持英语与简体中文双向整句翻译。翻译默认关闭；勾选侧栏按钮、打开面板或选择「离线整句」均不会下载或启动模型。只有点击「下载离线组件」才安装，点击「开始离线翻译」才运行。

## 使用与资源生命周期

在「设置 → 侧栏」勾选翻译，打开翻译面板后选择「离线整句」和语言方向。首次下载包含共享运行时及当前方向的语言包，切换方向时只补充缺少的语言包。「开始离线翻译」旁的「AI 翻译」可直接处理同一原文，AI 无需安装离线组件和词库。

输入文字或带入选区，点击开始。结果可编辑、复制、替换选区或保存到个人／项目库，替换前检查原文是否变化及占位符是否完整。右上角的书本图标打开「词库管理」，可下载语言包或移除双向组件。下面的耗时和内存数据供开发验证。

推理使用短时独立进程，每次结果返回前进程已退出，解释器和模型内存由 Windows 回收。取消或关闭面板会结束任务并清理未完成的下载，打开词库管理或切换页面时下载可继续。完成的组件保留在 `data/translation-offline`，下次翻译无需联网。

## 实际下载与安装大小

下表来自完整下载文件长度及安装后文件统计，**MiB = 1,048,576 字节**。安装大小是文件长度之和，含小型安装清单；不是 NTFS 分配簇大小，也不包含安装期间的临时 ZIP。共享运行时只安装一次。

| 组件 | 实际下载字节 | 下载 | 安装后字节 | 安装占用 |
| --- | ---: | ---: | ---: | ---: |
| 共享运行时 | 36,202,598 | 34.5 MiB | 95,487,746 | 91.1 MiB |
| 英语 → 简体中文 1.9 | 70,743,021 | 67.5 MiB | 84,888,052 | 81.0 MiB |
| 简体中文 → 英语 1.9 | 74,481,402 | 71.0 MiB | 84,886,873 | 81.0 MiB |
| 双向合计 | **181,427,021** | **173.0 MiB** | **265,262,671** | **253.0 MiB** |

只安装英译中时首次下载 **102.0 MiB**，安装约 **172.0 MiB**；只安装中译英时首次下载约 **105.6 MiB**。这些文件不进入 EXE。安装完成后删除下载临时文件，不保留原始模型压缩包。

公开测试版 EXE 为 **39,504,384 字节（37.7 MiB）**；上一轮侧栏测试版为 39,403,008 字节，本轮增加 **101,376 字节（99 KiB）**，没有增加 Go 依赖或嵌入运行时、权重。

共享运行时为官方 CPython 3.13.17 Windows 嵌入包、CTranslate2 4.9.1 wheel、SentencePiece 0.2.3 wheel，共三个归档。单文件下载分别为 11,441,267、23,105,788、1,655,543 字节；本机首次获取分别用时 2.53、3.15、1.98 秒，中英语言包分别为 6.55、6.07 秒。网络时间取决于网络及代理，不能作为其他机器的承诺。

另通过真实界面按钮使用生产 HTTP 客户端从官方源完成首次英译中安装：实际接收 **106,945,619 字节**，下载并安装 **24.10 秒**；成功翻译短句后从组件管理中移除，验证文件清理。Windows 新解压 DLL 被短暂占用时，安装目录切换会在可取消的 10 秒窗口内重试，不修改系统防护设置。

没有安装完整 Argos Python 应用、pip、PyTorch、Stanza、NumPy 或 PyYAML。模型包只提取实际推理所需的权重、配置、词表、SentencePiece、元数据和 README。运行时包含依赖包的许可文件，并复用 SentencePiece 官方 wheel 附带的 Microsoft C++ 运行库 DLL；实测 CTranslate2 加载的是组件目录内的 `msvcp140.dll`，无需修改系统环境或管理员安装。

## 翻译耗时与内存

机器：Intel Core Ultra 9 285H，32 GB RAM，Windows 11 家庭中文版 10.0.26300。CPU 推理最多 2 线程、beam size 2。每项执行 3 次，每次均启动新进程、重新加载模型；时间包含启动、加载、推理和退出。没有清空 Windows 文件缓存，不代表冷磁盘或低配电脑的速度。

| 样例 | 输入 | 3 次中位耗时 | 本组最高峰值工作集 | 推理结束时最高私有提交 |
| --- | --- | ---: | ---: | ---: |
| 英译中短句 | Please save your changes before closing this window. | 380 ms | 129.2 MiB | 125.2 MiB |
| 中译英短句 | 请在关闭窗口前保存更改。 | 357 ms | 129.5 MiB | 125.6 MiB |
| 英译中段落 | 3 句网络错误与草稿提示 | 405 ms | 133.9 MiB | 125.2 MiB |
| 中译英段落 | 3 句网络错误与草稿提示 | 403 ms | 134.2 MiB | 124.8 MiB |
| 带占位符及换行 | Saved {count} files to ${folder}.\nUse `Ctrl+S` to save. | 415 ms | 129.4 MiB | 125.3 MiB |

安装后的首次英译中耗时 **847 ms**，之后两次为 380、360 ms；译文为「请在关闭此窗口前保存您的更改。」中译英样例返回 “Save the changes before closing the window.”。

内存数字来自翻译子进程的 `GetProcessMemoryInfo`，不包含 EditorX 主程序。峰值工作集包含映射的共享页，私有提交是推理结束时读数，两者口径不同。每次 Go `Run` 等待进程退出后才展示结果，因此完成后翻译子进程占用归零；系统文件缓存仍由 Windows 管理。400 ms 超时取消长文本的实测在 2 秒内结束，没有留下工作进程。

初测发现 Windows MKL 预打包会产生约 908 MiB 私有提交；设置 CTranslate2 官方支持的 `CT2_USE_MKL=0` 后，上表实测约 125 MiB，短文本速度相当。正式实现已固定该设置。

原始记录：开发输出 `.dev/offline-translation/data/offline-measurements.json`，每次包含输入、译文、加载／推理／总耗时及内存；下载记录在同目录的 `downloads/downloads.json`，其中早期探测的 NumPy、PyYAML 不属于最终安装组件。

## 词库的 6.5 MiB 与下载量

ECDICT 筛选后的 **69,291 条词与词形释义占 6,805,702 字节，即 6.49 MiB**。这是本地词库占用，不是从官方源获取的下载量。

官方固定版本 CSV 的 gzip 响应实测 **22,724,903 字节，即 21.67 MiB**，源 CSV 解压后为 **66,009,548 字节，即 62.95 MiB**。界面使用压缩下载实测值作预估，进度显示实际收到的字节，安装清单记录下载量。

压缩响应通过了完整 SHA-256、解压长度和安装查询验证。安装流式筛选，原始 CSV 不保留。词库与整句模型完全独立。

## 实现边界与来源

- 当前面向 Windows x64；最多 8 KiB 原文。CPU 模型适合日常提示、邮件和短段落，译文仍需人工核对。
- 分句使用轻量规则，长句按 256 token 分块，避免静默截断。代码片段、占位符和链接目标保留原文；占位符两侧分段翻译可能影响语序，替换前应预览。
- 所有归档固定版本、长度和 SHA-256；拒绝 ZIP 路径越界及异常大文件，完成后才发布安装目录。支持取消、失败重试和组件移除；当前没有离线包导入和断点续传。
- [Argos 官方模型目录](https://data.argosopentech.com/argospm/v1/)提供两个 1.9 中英包，随模型保留的 README 包含 OPUS 来源、作者及 CC BY 4.0 许可。
- [CTranslate2 4.9.1](https://pypi.org/project/ctranslate2/4.9.1/)、[SentencePiece 0.2.3](https://pypi.org/project/sentencepiece/0.2.3/)、[Python Windows 发行版](https://www.python.org/downloads/windows/)为运行时来源。固定下载地址与 SHA-256 见 `internal/editor/offline_translation_packages.go`。
- [CTranslate2 环境变量](https://opennmt.net/CTranslate2/environment_variables.html)说明 CPU 后端和线程控制；分词参考 [Argos tokenizer 实现](https://github.com/argosopentech/argos-translate/blob/master/argostranslate/tokenizer.py)。
