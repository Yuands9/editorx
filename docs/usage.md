# Viva Editor 使用指南

## 打开文件和项目

运行 `VivaEditor.exe`。将本地文件或文件夹拖到 EXE 上也可以打开它们。按 Ctrl+O 可以选择一个或多个文件。按 Ctrl+Shift+O 添加项目文件夹，点击左侧项目树里的文件即可打开。项目的「…」菜单支持打开资源管理器、打开 Git 或终端、刷新和移除项目。收起侧栏后，顶部仍可打开文件、添加项目和恢复侧栏。

点标签栏加号或双击空白处可新建标签。关闭最后一个标签后，中央会显示打开文件和最近文件入口。标签可拖动排序、右键重命名或加入分组，输入新名称后按 Enter 确认。点组名展开或收起，拖组名可移动整组。固定的标签受关闭保护，先取消固定再关闭。右键已保存的标签可打开文件所在目录。

## 编辑、查找和保存

编辑区支持 UTF-8 文本、UTF-8 BOM、LF 和 CRLF。文件类型默认按名称和后缀识别，点击右下角的类型可为当前标签手动选择语法。切回「自动识别」即可恢复默认行为。

Ctrl+F 打开查找浮窗，按住标题栏可拖动。查找支持区分大小写、全词、循环和 Go 正则表达式。在「查找全部已打开文档」中，结果按文件分组，点命中行可回到正文。查找框打开时使用 Enter 或 Shift+Enter 找下一处或上一处，关闭后可继续使用 F3 或 Shift+F3。

Ctrl+S 保存，Ctrl+Shift+S 另存为。保存时会核对原文件的磁盘状态。文件已被别的程序改动时，可另存为一份新文件以保留两份内容。关闭单个有修改的标签会询问处理方式。关闭窗口时未保存草稿可随本地会话恢复。

## JSON 和预览

打开 JSON 后，左侧编辑原文，右侧显示处理结果。常用操作包括格式化、压缩、键排序和结构对比。「更多」里有 Form-Data 文本、XML、转义和 Unicode 转换。格式化后可在行号边逐个收起对象和数组。点「应用」才会把同格式结果写入原文，也可先复制或另存。JSON 和 Markdown 分屏可通过工具行控制同步滚动。

Markdown 支持分屏和大纲。HTML 支持编辑、分屏或完整预览，点「刷新预览」可重新渲染未保存的内容。网页中的 JavaScript、CSS 和相对资源按浏览器规则运行。依赖 HTTP 接口的页面可通过项目自己的开发服务运行。

## Office、PDF 和图片

打开 `.xlsx` 可编辑单元格、常用公式和格式，打开 `.docx` 可编辑正文、段落、表格和图片。Ctrl+S 保存，Ctrl+Shift+S 另存为。旧格式 `.xls` 和 `.doc` 可先另存为对应的新格式。中文输入法选词完成后再保存。

PDF 支持翻页、缩放、查找和另存原件。Excel 编辑界面、Word 和 PDF 阅读区随当前窗口的主题切换，文件里的颜色会随内容保存。XMind 和图片在独立标签中只读查看。

## AI 助手、Git 和终端

右侧工具栏可打开 AI 助手。先在「模型设置」里添加 API 服务或已登录的本机 CLI，再从输入框右下角选择模型和思考水平。使用已登录的 CLI 时，模型配置沿用该 CLI 的本机登录状态。API 密钥可在输入框内点眼睛显隐。发送时会使用输入框列出的上下文，点上下文标签的关闭按钮可将其移除。生成修改和新建草稿都可以先审阅再应用。拖选消息中的文字可复制选区，消息按钮可复制全文。聊天记录可从顶部时钟图标打开、重命名和删除，本地会保留对话。

通过项目菜单打开 Git 或 PowerShell 可直接定位到项目。Git 面板使用本机 Git for Windows，可查看工作区变更、暂存、提交及同步。终端使用 Windows PowerShell，Ctrl+Shift+C 复制，Ctrl+Shift+V 粘贴。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新文件 / 新窗口 | Ctrl+N / Ctrl+Shift+N |
| 打开文件 / 添加项目 | Ctrl+O / Ctrl+Shift+O |
| 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S |
| 关闭当前标签 | Ctrl+W |
| 下一个 / 上一个标签 | Ctrl+Tab / Ctrl+Shift+Tab |
| 文件栏 / Markdown 大纲 | Ctrl+B / Ctrl+Alt+B |
| 自动折行 | Alt+Z |
| 查找 | Ctrl+F |
| Git / 终端 | Ctrl+Shift+G / Ctrl+Alt+T |

默认数据目录为 EXE 同目录的 `data`。其中包含会话、草稿、最近文件和 AI 设置。可通过环境变量 `VIVA_EDITOR_DATA_DIR` 为独立实例指定其他目录。
