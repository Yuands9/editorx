# EditorX 使用指南

## 打开文件和项目

下载 [Windows 版 EXE](https://github.com/Yuands9/editorx/releases/latest/download/EditorX.exe) 到有写入权限的目录，双击运行下载的 EXE。可以把文件拖入 EditorX 窗口打开，也可以拖到 EXE 图标上。文件夹拖入后作为项目添加。64 MiB 及以上的本地纯文本、日志和 .out 文件默认按页浏览，可滚轮翻页、复制选区、查看全局行号、查找全部或跳到文件末尾。需要修改时点「打开完整编辑」。按 Ctrl+O 可以选择一个或多个文件。按 Ctrl+Shift+O 添加项目文件夹，点击左侧项目树里的文件即可打开。项目的「…」菜单支持打开资源管理器、打开 Git 或终端、刷新和移除项目。确认移除后会关闭归属该项目的标签，未保存的修改按常规流程处理。取消保存确认时保留项目和标签，已经保存的文件会保留新内容。收起侧栏后，顶部仍可打开文件、添加项目和恢复侧栏。

欢迎页提供「打开文件」「打开项目」和「最近打开文件」。以 `EditorX.exe` 文件名运行时，EditorX 默认在当前 Windows 用户环境中登记 `EDITORX_HOME` 和 PATH。首次运行后重新打开终端，可执行 `editorx`、`editorx .` 或 `editorx "路径\文件.txt"`。移动 EXE 后从新位置运行一次即可更新登记。

新版可在「设置 → 关于 → Windows 打开方式」点击「添加到打开方式」。旧版可在资源管理器中右击文件，选择「打开方式 → 选择其他应用 → 在电脑上选择应用」，选中旧版的 `EditorX.exe`，再选择「仅一次」。要批量添加常见格式，把 [register-open-with.ps1](../tools/register-open-with.ps1) 下载到本机，再在脚本所在目录用 PowerShell 执行下方命令。注册仅对当前 Windows 用户生效，保留原来各文件类型的默认应用。Windows 11 中「使用 EditorX 打开」也可以从「显示更多选项」找到。移动 EXE 后重新登记一次。

```powershell
.\register-open-with.ps1 -Executable 'D:\software\EditorX\EditorX.exe'
```

打开文本时会尝试识别 UTF-8、UTF-16、GBK、GB18030 和 Windows-1252。从主菜单「文件与标签 → 按编码打开」可直接指定编码，打开后也可点击右下角编码，再选「按编码重新打开」。可手动选择 Big5、Shift-JIS 或 ISO-8859-1。需要修正乱码时用重新打开；需要改变文件的保存编码时用「转换编码（保存后生效）」。转换列表已包含 GB18030、UTF-16 LE 和 UTF-16 BE，可与 UTF-8 相互转换。UTF-8 可选带 BOM 或不带 BOM，UTF-16 转换使用 BOM。点击右下角 LF／CRLF／CR 可统一换行格式。转换会标记未保存，Ctrl+S 后写入文件；目标编码不能表示某些字符时保存失败，原文件保留。仅转换格式的草稿也会随会话或恢复关闭标签保留。

打开本地文本时，如果内容是 JSON 对象、数组或带有明确 Markdown 标记，且后缀对应的格式不同，EditorX 会提示选择显示格式。选择「保留原格式」会按后缀打开，确认后仅切换当前标签的显示格式。批量打开时，其余文件在切换到各自的标签后提示。

点标签栏加号或双击空白处可新建标签。新建空白标签或关闭最后一个标签后，中央显示「开始编辑」，按顺序提供「打开项目」「打开文件」「最近打开文件」，下方列出最多三个最近文件。空白标签可以直接输入，开始输入后欢迎区自动隐藏。标签可拖动排序或通过右键菜单加入分组。双击标签名或组名可重命名，按 Enter 确认。单击组名展开或收起，拖组名可移动整组。固定的标签和分组可以直接关闭。批量关闭会跳过固定项。右键已保存的标签可打开文件所在目录。

在主菜单选择「文件与标签 → 打开链接文件」，或按 Ctrl+Shift+L，粘贴 HTTP 或 HTTPS 链接后回车。支持图片、PDF、Word（DOCX）、JSON、Markdown、JavaScript 等。单个链接文件最大 128 MiB。点「打开」可临时查看，选择「保存并打开…」后可指定本地保存位置。临时文本可以编辑，按 Ctrl+S 选择保存位置。仅查看的链接标签会在退出时关闭，编辑后的未保存草稿可以随会话恢复。打开链接的快捷键可在设置中修改。

## 快速打开、命令与快捷键预设

Ctrl+P 打开快速文件面板，搜索当前窗口已打开的标签、最近文件和已添加项目中的文件。支持中文、文件名、路径片段和连续字符缩写；相同文件名会同时显示路径。↑／↓ 选择，Enter 打开，Esc 返回原编辑区。已打开的文件直接切换标签，不重复打开。列表最多显示 100 项，可继续输入缩小范围。

项目扫描在后台进行，关闭面板即取消；每次打开重新扫描，不创建磁盘索引。跳过 .git、.hg、.svn、node_modules 和 .dev，最多检查 20,000 个目录项，并在超过约 3 秒后停止继续遍历。未完整列出时面板会提示，可用 Ctrl+O 选择文件。

Ctrl+Shift+P 打开命令面板，可按当前菜单语言的名称、中文名称或命令标识搜索文件、编辑和工作区操作，并查看当前快捷键。当前不可用的操作会置灰。主菜单保留新建、打开、快速打开、保存、全部保存等高频入口，其余放入「文件与标签」「编辑与查找」「工具与模板」。JSON 同步滚动图标位于 JSON 操作栏，不再单独占一行。

「设置 → 快捷键」提供 EditorX、Notepad++、Sublime Text、EditPlus、IntelliJ IDEA、PyCharm 和 VS Code 预设。页首可按命令名、命令标识或组合键筛选，例如 `保存`、`gitCommit` 或 `Ctrl+K`。切换会替换自定义快捷键，修改后显示「自定义」，也可恢复 EditorX 默认。预设自动保存并同步到同一实例的其他窗口。Sublime 预设中 Ctrl+D 选择单词／下一个相同内容，Ctrl+Shift+L 拆分多行选区，打开链接使用 Ctrl+Alt+L，Ctrl+L 留空。

| 预设 | 替换 | 另存为 | 全部保存 | 复制行 | 删除行 |
| --- | --- | --- | --- | --- | --- |
| EditorX | Ctrl+R（兼容 Ctrl+H） | Ctrl+Shift+S | Ctrl+Alt+S | Ctrl+D | Ctrl+L |
| Notepad++ | Ctrl+H | Ctrl+Alt+S | Ctrl+Shift+S | Ctrl+D | Ctrl+L |
| Sublime Text | Ctrl+H | Ctrl+Shift+S | Ctrl+Alt+S | Ctrl+Shift+D | Ctrl+Shift+K |
| EditPlus | Ctrl+H | Ctrl+Alt+S | Ctrl+Shift+S | Ctrl+J | Ctrl+L |
| IntelliJ IDEA | Ctrl+R | Ctrl+Shift+S | Ctrl+S | Ctrl+D | Ctrl+Y |
| PyCharm | Ctrl+R | Ctrl+Shift+S | Ctrl+S | Ctrl+D | Ctrl+Y |
| VS Code | Ctrl+H | Ctrl+Shift+S | Ctrl+Alt+S | Alt+Shift+↑／↓ | Ctrl+Shift+K |

IntelliJ IDEA 与 PyCharm 预设按 JetBrains Windows 键位适配 EditorX 已支持的操作。Ctrl+Shift+N 搜索文件，Ctrl+Shift+A 打开命令面板，Ctrl+E 查看最近打开。Alt+←／→ 切换标签，Ctrl+Alt+←／→ 导航历史，Ctrl+F4 关闭当前标签。Ctrl+Shift+F／R 在目录中查找／替换，Ctrl+/ 切换支持语言的行注释。[IntelliJ IDEA 快捷键](https://www.jetbrains.com/help/idea/reference-keymap-win-default.html) · [PyCharm 快捷键](https://www.jetbrains.com/help/pycharm/mastering-keyboard-shortcuts.html)

Alt+1 切换项目栏，Alt+F1 在项目中定位当前文件，Alt+9 打开 Git，Ctrl+K 定位到提交说明，Alt+F12 打开终端，Ctrl+Alt+S 打开设置。正文里 Ctrl+Y 删除行，Ctrl+Shift+Z 重做，表单里的 Ctrl+Y 仍可重做。全部保存使用 Ctrl+S，单文件保存可点工具栏。单文件保存与新建窗口可在设置中另外绑键。

VS Code 预设适配 EditorX 中已有的高频操作。Ctrl+Shift+H 在目录中替换，Ctrl+D 选择下一处相同内容，Ctrl+Shift+L 选择全部相同内容，`` Ctrl+` `` 切换终端。用 Ctrl+Alt+Shift+方向键做列选择，Ctrl+Alt+L 打开链接文件。手动补全使用 Alt+/，全部保存用 Ctrl+Alt+S。[VS Code Windows 快捷键](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf)

Ctrl+Shift+T 按关闭顺序恢复标签，也可从标签右键或「主菜单 → 文件与标签」进入。当前窗口最多保留 20 个关闭记录，普通文本快照合计最多 16 MiB。符合容量限制的普通草稿可恢复未保存文本与选区；未修改的文件重新读取磁盘最新内容。大文件及 Office／预览文件从磁盘重新打开。临时链接和超过容量限制的未命名文本不保留关闭快照；关闭记录仅在本次窗口运行期间有效。

全部保存处理当前窗口内所有有修改的文件，包括先前恢复但尚未激活的大文件草稿。未命名文件逐个选择保存路径。取消另存为或遇到磁盘冲突时停止，已保存部分保留，其余草稿继续留在标签里，状态栏显示完成数量。

## 目录全文查找

按 Ctrl+Shift+F，或在项目／目录右键选择「在此目录中查找…」。可更换搜索目录、递归查找子目录；「包含文件」支持如 `*.go;*.md`，排除项按文件或目录名称匹配，以分号分隔。支持区分大小写、整词和 Go 正则。默认排除 .git、.hg、.svn、node_modules、.dev，不跟随符号链接。

开始搜索后，结果显示在底部常驻面板，包含路径、行号、列号和正文片段；点击或按 Enter 跳转后仍可继续编辑。已打开文件使用开始搜索时的编辑内容，包括未保存修改；其他文件读取磁盘。跳转时重新定位当前内容，不覆盖草稿。「搜索选项」可调整条件，「停止」取消搜索，关闭结果面板也会停止未完成的搜索。

每次最多展示 5,000 个匹配、遍历 100,000 个目录项；磁盘单文件最大 64 MiB。二进制、不可读和超限文件计入跳过数量，停止或截断会提示结果不完整。大日志可单独打开使用全文查找。目录搜索不建立磁盘索引。

在结果面板填写替换内容（允许留空），点击「预览替换」查看每个文件的替换数量及片段，勾选需要修改的文件，再点击「替换所选」。正则分组可用 `$1` 等引用。已打开文件的替换写入编辑区，可用 Ctrl+Z 一次撤回，仍需手动保存；未打开文件保持原编码、BOM 和换行写回磁盘，并遵循本地历史设置。预览后内容发生变化的文件会跳过并说明原因。结果不完整时须先缩小搜索范围；停止替换会完成当前文件，随后不再处理其他文件。

项目目录在后台加载和刷新。资源管理器中的新增、删除和重命名会自动更新目录树；移除项目或关闭窗口会释放监控。点击项目栏准星按钮「定位当前文件」，或标签右键「在项目中定位」，展开并滚动到当前文件。旁边的双箭头用于全部展开或全部收起已添加的项目。展开在后台读取目录。项目、文件和标签右键均可复制完整路径、相对项目路径和文件名。

单击项目文件使用一个可复用的「预览」标签；再次快速点击同一文件、双击预览标签或选择「保留此标签」可保留。编辑、保存、固定或加入分组后自动保留。已有草稿不会被下一个预览文件替换。目录查找和自定义工具优先使用当前文件所属的最内层项目；多项目下无对应文件时不默认使用无关项目。

Ctrl+/ 按语言添加或移除选中行的注释，支持 Go、Java、JavaScript、TypeScript、C/C++、C#、Rust、Kotlin、Python、Shell、PowerShell、YAML、TOML、Properties、ENV、SQL 和 INI。可撤销，也可由宏录制和重放。

## 多光标与列编辑

- Alt+单击：添加光标；Alt+拖动：矩形列选区。列宽按 Tab 和中文字符的显示宽度计算，短行停在行尾。
- Ctrl+Alt+↑／↓：在上一行／下一行添加光标。
- Ctrl+Alt+D：无选区时先选中当前单词，再按选中下一个相同内容；Ctrl+Alt+Shift+D 选中全部相同内容。
- Ctrl+Alt+Shift+L：将当前多行选区拆成每行一个选区。Sublime 预设对应 Ctrl+D、Ctrl+Shift+L。
- 在多个选区输入、删除或粘贴会同时应用；复制按行拼接非空选区，Ctrl+Z／Ctrl+Y 撤销和重做整次编辑。Esc 只保留主光标。

这些命令也在「编辑与查找」、编辑区右键和命令面板中提供，可以改绑。最多支持 2,000 处选区；撤销后恢复为主选区。输入法组合期间由主光标接管输入，不新增多选区。大文件分页和完整编辑保留原有跨视口单选区；编码／换行转换也限普通文本编辑区。

## 文本与日志

- .log 和 .out 自动使用日志配色，区分时间戳、日志级别、请求标识、网址和嵌入的标签。
- 按页浏览的大文件可用 Ctrl+F 打开查找栏。浏览模式的查找区分大小写，选择「查找全部」可在底部查看结果。点击结果可跳到对应行，正文会高亮当前页的匹配。结果最多显示 10,000 处匹配。
- 点击「打开完整编辑」后，右侧滚动条可跳到文件任意位置。可以跨视口选择、剪切、粘贴和撤销。Ctrl+F 和 Ctrl+R 打开查找或替换浮窗，支持全文查找、正则和跨文档替换。Ctrl+S 沿用原编码、BOM 和换行保存。点击「退出完整编辑」可回到进入编辑前的浏览页。有未保存修改时可选择保存、放弃或取消。重新打开会话会恢复位置和未保存的改动。
- Ctrl+G 转到全局行号。Ctrl+F2 切换当前行的书签，F2 和 Shift+F2 在书签间跳转。
- 主菜单「编辑与查找 → 文本操作」可显示空白字符和换行符。可编辑文档支持复制行（Ctrl+D）、移动行和删除行（Ctrl+L）。普通文本还支持大小写转换、行排序和删除空白行。排序与清理在有选区时处理选中的行，空选区时处理当前文档。

## 设置

「设置 → 外观 → 界面语言」可选择「简体中文」或「English」。菜单、状态栏、设置、工具侧栏、对比窗口和内嵌预览会随语言切换，同一实例的其他窗口也会更新。重启后沿用所选语言，可从 **Settings → Appearance → Interface Language** 切回。

点击侧栏底部齿轮或按 Ctrl+, 打开或关闭设置，也可从主菜单进入。左侧按外观、编辑器、侧栏、存储管理、快捷键、AI、更新和关于排列，顶部可以搜索设置。选择会即时生效并自动保存。

「外观」提供跟随系统、深色和浅色。首次运行默认跟随 Windows 应用主题。右下角的主题按钮在深色和浅色之间直接切换。要恢复跟随系统，可在「外观」里选择。默认显示托盘图标。关闭单个窗口时，其他窗口继续打开。关闭最后一个窗口时，应用会保存会话并按设置退出或隐藏到后台。

「编辑器」可设置字体、字号、Tab 缩进、默认折行和输入时自动补全，并提供实时预览。JSON 格式化缩进可在文档工具栏选 2 或 4 个空格。在「快捷键」中点击某项的按键，按下新的组合键或功能键即可改绑，也可清除绑定和恢复默认。AI 面板的「模型设置」可直达「AI」。填写模型配置后，点「保存配置」或按 Enter 保存。切换到其他设置分类时，表单会保留本次填写的内容。

在「设置 → 关于 → 应用配置」中，可以把外观、编辑器、侧栏和快捷键等应用设置导出为 JSON。导入 JSON 或恢复默认配置都需确认，结果会应用到所有窗口。已打开的文件、草稿、AI 配置和密码本继续各自保存。

「设置 → 存储管理」分别显示应用数据、历史版本和总占用，可刷新统计或打开数据目录。应用数据中列出可清理和不可清理的大小。「清理缓存」会清除残留 HTML 预览和闲置 AI CLI 临时文件，完成后更新统计。

点「管理历史版本」可查看各版本大小。点击文件行可展开或收起版本，勾选复选框可选择文件的全部版本或单个版本进行清理，也可确认清空。EditorX 保存改动并覆盖本地文件时，会为覆盖前大小在 32 MiB 以内的版本记录快照。大小按压缩前计算。默认每个文件保留最近 30 天内的最新 20 个版本，两项限制可分别设置，填 0 表示不限。更改规则后会清理超过期限或数量的历史，也可以暂停记录。

项目文件、正文或标签右键的「比对历史」会打开独立窗口。可拖动标题栏移到其他显示器，也可拖动边框调整大小。左侧历史只读，右侧当前版本可编辑，与主窗口共用编辑缓冲区。比对未打开的文件时，首次编辑或合并会为它打开一个标签。工具栏用上下箭头循环跳转区别，可切换「展示全文件」和「只看区别」。精简视图在每块改动前后保留最多四行，并标出省略的行数。

点击差异块的中央箭头或「合并此区别」，可把该块历史改动合并到编辑区。「恢复整个版本」会一次应用该版本的文本。编辑和合并都能在比对窗口用 Ctrl+Z 撤销，按 Ctrl+S 保存。普通文本的历史和当前版本各支持最多 32 MiB、105 万行。一次合并超过撤销容量时，可逐块合并或另存历史副本。「另存副本」可导出完整版本，也适用于大文件、Office 文档和已删除的文件。

默认每次启动约 10 秒后检查新版本，运行期间每 6 小时检查一次。发现新版时，工具侧栏底部出现绿色下载图标，未打开文件也能看到。点击可查看版本、下载大小和更新内容。可在「设置 → 更新」关闭自动检查，或手动「检查更新」。进入更新页时只请求最近 5 条发布记录，点「加载更多版本」才会请求下一页。点击版本行可展开说明，也可通过对应的 GitHub Release 下载。

「更新 → 更新下载源」可切换 GitHub 和 CNB。GitHub 为默认来源。选择 CNB 时自动使用 EditorX 官方镜像，也可以更改镜像地址。新版发现、版本历史和 SHA-256 继续由 GitHub 提供，CNB 下载或校验失败时回退 GitHub。

排查故障时可在「关于」临时打开调试日志。日志在当前窗口内存中最多保留 1 MiB，可清空、复制或通过「下载日志」保存为 `.log`。关闭窗口、关窗进入托盘或退出应用都会清除日志并关闭该开关。

「稍后」关闭弹窗并保留图标；「跳过此版本」只隐藏该版本，下个新版仍会提示，手动检查也能查看已跳过的版本。点击「下载更新」后可选择「后台下载」继续编辑，也可取消。下载和校验完成后，再点击「安装并重启」；应用先保存所有窗口的会话和草稿，保存失败会保留当前应用。多个窗口共用检查和下载任务。含 Word 编辑的本机构建可从弹窗下载公开版。

GitHub API 返回 403 或 429 时，EditorX 会尝试从公开发布页识别新版本并提供发布页入口。应用内下载安装需要已校验的发布元数据。

点击托盘图标可恢复窗口。右键可打开设置或彻底退出。隐藏时也可双击原快捷方式或 `EditorX.exe` 恢复已有窗口，即使托盘图标关闭也可以。要主动添加一个工作窗口，使用 Ctrl+Shift+N。

## 编辑、查找和保存

编辑区支持多种文本编码以及 LF、CRLF 和混合换行。文件类型默认按名称和后缀识别，无后缀的未保存标签会根据正文识别。右下角可为当前标签手动切换文件类型，编辑布局和语法高亮随之更新。「自动识别」可恢复默认行为。

右键正文可撤销、重做、剪切、复制、粘贴、删除选区或全选，也可打开查找、替换和转到行。按页浏览大文件时，可全选当前页、复制、查找或转到行。正文获得焦点后也可用 Shift+F10 打开菜单。

Ctrl+F 打开查找浮窗，Ctrl+R 直接打开替换，按住标题栏可拖动。查找支持普通文本、转义字符、Go 正则、区分大小写和全词匹配。「查找全部已打开文档」在底部按搜索词、文件和命中行分组。同一行的多个命中合并高亮，标题统计命中总次数。搜索词和文件标题可以折叠，长行可横向滚动，点击结果可定位到正文。Enter 或 Shift+Enter 找下一处或上一处，关闭浮窗后可继续用 F3 或 Shift+F3。

在查找或替换框中可直接粘贴多行文本，也可按 Ctrl+Enter 换行。转义字符模式接受 `\n`、`\r\n`、`\t` 和 `\\`。正则替换支持 `$1` 和命名分组引用。可以替换当前匹配、当前文件的全部匹配，或当前窗口所有已打开的可编辑文本标签。替换写入编辑缓冲，按 Ctrl+S 保存，批量替换可在各文件中撤销。

Ctrl+S 保存，Ctrl+Shift+S 另存为。保存时会核对原文件的磁盘状态。文件已被别的程序改动时，可另存为一份新文件以保留两份内容。关闭有修改的标签时，可以勾选「不再询问」。之后关闭标签会自动保存，未命名文件会弹出保存位置。可在「设置 → 外观 → 关闭标签时询问保存」中重新开启提示。

退出 EditorX 时，确认框会显示有未保存修改的文件总数，最多列出五个文件名。「保留草稿并退出」会保存会话草稿，「保存并退出」会保存所有有修改的文件。点右上角的关闭按钮可取消退出。勾选「以后退出时不再询问」，或在「设置 → 外观」关闭「退出时询问保存」，以后退出时将直接保留草稿。下次打开可从会话中恢复。

在「设置 → 编辑器」可选择系统已安装的等宽字体和字号，设置 Tab 的列宽以及插入空格或 Tab 字符。在「默认自动折行」中打开相应文件类型的开关，默认仅为 JSON 开启。标签手动选择的折行和 JSON 缩进优先于全局默认值。

新窗口默认展开左侧主菜单和项目栏，可用 Ctrl+B 收起或展开。会话会记住上次的栏位状态。「侧栏」可选择工具按钮和面板的位置，也可单独隐藏设置齿轮。所有按钮都隐藏时，整列工具侧栏收起。发现新版时，更新提示会显示在所选侧。没有文档时，保存、查找和折行按钮置灰。模板库和翻译的侧栏图标默认隐藏。

## 新建与模板

Ctrl+N 和标签栏的加号直接打开空白标签。加号旁的箭头可以按格式新建或选择「从模板新建」。在「设置 → 侧栏」打开「模板库」后，也可点击侧栏的模板图标。

模板库在侧栏打开，编辑区仍可操作。搜索并点击模板卡片，填写变量、查看预览，然后点「创建草稿」或「插入当前文档」。插入时有选区则替换选区，否则插入当前光标位置，Ctrl+Z 可撤销。返回箭头可回到模板列表。Markdown 模板显示排版后的预览。

- 从主菜单将整篇文档或选区存为模板。要加入变量，在弹窗正文中选中文字，点击「设为变量」，再填写变量名。当前项目可用时，可在「保存到」选择个人库或项目库。「保存并预览」会在侧栏打开该模板。
- 编辑或新增：在模板预览点「编辑模板」，或在模板列表底部点「新建模板」。个人模板可跨项目使用，项目模板随当前项目显示。
- 右键项目目录，选「新建文件」可自定义文件名或使用常见格式。切换到「模板」即可从模板创建。「自定义」按输入的名称创建，支持任意后缀和无后缀。选用格式预设时，省略后缀才会自动补齐。选「新建文件夹」可直接输入名称。
- 只有一个子目录且没有文件的连续层级会合成 `src.main.java` 这样的一行。右键默认操作末级目录，也可通过「上级目录」选中合并路径中的其他层级。项目根目录、子目录和文件都可从右键菜单重命名。

个人模板保存在本机数据目录的 `templates.json`，项目模板保存在项目的 `.editorx/templates.json`。

## 密码本

从「主菜单 → 密码本」在正文旁打开密码本，也可在「设置 → 侧栏」打开密码本按钮。首次使用时可以设置至少 8 个字符的主密码，也可以由当前 Windows 账户保护并直接打开。用备份密码恢复 `.edxvault` 加密备份。密码本条目保存在独立的本机加密库中。

- 拖动分隔条可调整密码本宽度。点条目进入详情，用「返回条目列表」保留原筛选。支持按名称、账号、网址或标签组合搜索，条目可以收藏或右键复制。侧栏标题旁的锁和关闭按钮分别用于锁定和收起。
- 新密码本只有一个「默认分组」。点击分组图标或名称可以展开分组，也可在新建条目时直接新建并选中分组。右键点分组可重命名，也可在其中新建子分组或条目。点箭头可展开或收起子分组。「全部条目」可跨分组搜索。右键分组和条目可打开删除确认。删除分组会移除其子分组，并按确认框所示迁移条目。
- 同一分组、同一网站来源下的多个账号集中显示，可展开单独查看。点「添加同站点账号」会预填网址和分组，每个账号单独保存。
- 在密码本点「从文本识别」粘贴内容，也可以在编辑器选中文字，右键点「识别到密码本」。支持账号密码标签和 Markdown 表格，选中需要保存的结果，再确认目标分组。
- 密码输入框可点小眼睛显示明文，再选中文字按 Ctrl+C 复制。条目详情的复制按钮默认在 20 秒后清理剪贴板，可在密码本设置中自定义秒数或关闭清理。
- 「密码本设置」可启用或关闭主密码，并自定义闲置自动锁定的分钟数或关闭闲置锁定。默认闲置 5 分钟锁定。切回文档、关闭密码本或 Windows 锁屏时会锁定。关闭主密码后由当前 Windows 账户保护加密库。
- 忘记主密码时，从锁定页点「忘记主密码？创建新密码本」。旧库会加密归档。想起原密码后，在锁定页或「密码本设置」中点「恢复旧密码本…」，按时间选择归档。恢复时可选择合并当前库的分组和条目，当前库也会保留一份归档。
- 导出可迁移的加密备份时，启用主密码的密码本沿用主密码，关闭主密码的密码本可单独设置备份密码。恢复备份适用于尚未创建密码库的环境。

## 翻译

选中文字后右键点「去翻译」，选区会带入翻译面板。也可以在「设置 → 侧栏」打开翻译图标，从图标进入后粘贴原文或点「查选区」。

- 「AI 翻译」使用选定的服务、当前原文、语言方向和匹配的项目或个人术语。配置一个服务时直接开始，有多个服务时先选择，未配置时可从按钮打开 AI 设置。
- 「本地翻译」先匹配已保存的译文。原文没有匹配项时，可用已安装的组件离线翻译整句。匹配到的术语和英汉释义可在「词义参考」展开。
- 译文可编辑、复制，也可点加号保存到个人或项目库。来自可编辑文本的译文可替换原选区，应用前会检查选区和占位符。JSON 仅支持替换字符串值内的文字。

面板右上角书本图标进入「词库管理」，可下载两个方向的离线组件和英汉词库，也可移除这些下载。个人和项目译文可在同一页添加、打开，以及导入导出 UTF-8 CSV。

在 Markdown 或纯文本正文右键点「整篇翻译」，选好语言后点「AI 翻译整篇」。最多支持 512 KiB，长文分段发送，译文在右侧流式显示。Markdown 完成后可按排版预览，代码块原样保留。可以停止翻译、复制已收到的译文，或用译文栏右上角的关闭按钮退出分屏。

英汉词库使用 [ECDICT](https://github.com/skywind3000/ECDICT)，保留 69,291 条常用词及词形释义。压缩下载实测约 21.7 MiB，安装后约 6.5 MiB，进度显示实际接收量。

个人库为本机数据目录的 `translations.csv`，项目库为 `.editorx/translations.csv`，每个自建库最多 2 MiB。项目、个人、下载词库按这一顺序匹配。下载词库保存在 `dictionaries/ecdict-common`。关闭翻译面板会取消任务并释放结果，已下载文件保留；移除下载词库不会删除个人和项目译文。

运行时、语言包和下载词库都需要主动安装。离线整句组件保存在 `translation-offline`，中英两个方向共用运行时，合计下载约 173 MiB。返回翻译面板时下载可继续，取消下载或关闭面板会清理未完成的安装。 [离线整句实测](offline-translation.md)

```csv
source_lang,target_lang,type,source,target,context
en,zh-CN,term,workspace,工作区,项目导航
en,zh-CN,sentence,Saved {count} files.,已保存 {count} 个文件。,保存结果提示
```

## 对比、磁盘变化与日志跟随

从主菜单「工作流 → 通用分屏对比」打开，或在普通文本编辑区右键选择「与其他文本对比」。左右都可选已打开的标签或磁盘文件，包括未保存草稿。左侧是读取时的参考快照，右侧共享当前标签的编辑内容。独立窗口支持拖到副屏、边框缩放、上下循环跳转区别、全文件／只看区别、逐块合并与整份采用；只看区别保留上下四行。右侧可继续输入，Ctrl+Z 撤回合并或编辑，Ctrl+S 保存。关闭对比窗口保留编辑结果，关闭右侧对应标签则关闭对比。

每份对比内容最多 32 MiB，过大或超过 105 万行会提示；大范围差异可能按整块展示，超出可撤销预算的合并不执行。需要切换参考来源时重新打开对比。

打开的本地文本被其他程序修改、替换、删除时，正文上方显示提示。可「比对磁盘内容」「重新读取」或「保留编辑内容」。有未保存修改时，重新读取需要再次确认；读取期间又发生编辑时，不覆盖新输入。保存时发现文件已变更，会询问是否覆盖文件、比对磁盘内容或重新读取。覆盖前会再检查一次磁盘版本，重新读取会放弃未保存的修改。也可以取消并另存文件保留两份。无法建立文件监听时，在切回窗口或选择「工作流 → 检查外部变更」时检查。

对已保存的日志／文本选择「工作流 → 跟随 / 暂停日志」，或在分页浏览工具栏点「跟随日志」。跟随使用只读分页视图，读取最后约 128 KiB，并在追加、截断、轮转后跟到新末尾。点「暂停跟随」、手动翻页或执行查找会暂停；继续跟随重新点按钮。修改前先暂停，选择「打开完整编辑」。跟随状态不跨重启保留。

## 宏与自定义工具

这些入口也可以用 Ctrl+Shift+P 搜索。选择「工作流 → 开始 / 停止录制宏」，在当前普通文本中用键盘输入、粘贴、删除、缩进或移动光标，再点正文上方「停止录制」。在「宏管理与重放」命名并保存，之后从下拉框选择宏，设置 1–100 次重复后重放。一次重放可以用一次 Ctrl+Z 撤销；输入法只记录提交的文字。上下及翻页键按逻辑行移动，鼠标选区按相对光标位置重放，建议使用键盘行首／行尾／上下移动录制可重复的操作。

宏用于 4 MiB 以内的单光标文本，每个最多 1,000 步和 256 KiB 录制文本，最多保存 30 个。遇到未支持的编辑操作会停止且不保存本次宏。重放在后台计算；超时、越界、结果超限或源文已改变时不部分应用。不录制打开文件、保存、外部进程、跨窗口或多光标操作。

「工作流 → 自定义工具」可以新建、选择、修改和删除工具。填写名称、程序名或可执行文件完整路径、参数（每行一个）及工作目录。支持变量 `{file}`、`{dir}`、`{project}` 和 `{selection}`，分别表示当前文件、所在目录、当前文件所属的最内层项目目录和当前选区。未打开文件且只有一个项目时可使用该项目；无法确定项目时提示选择文件。参数含空格时不用额外加引号。可勾选「将选区作为标准输入」；管道和脚本需要显式填写 PowerShell 等解释器。

点「运行工具」才启动进程，不会随文件打开或软件启动自动运行。输出和错误在弹框显示，可停止、关闭弹框取消，或将输出打开为新标签。每次最多运行 2 分钟，保留前 1 MiB 输出；弹框只预览前 16 KiB。标准输入和输出使用 UTF-8，工具应配置为读取及输出 UTF-8。工具最多保存 30 个，宏和工具共同写入数据目录的 workflow-settings.json，总配置上限 2 MiB；不会创建执行日志或另存输出文件。

## JSON 和预览

达到 1 MiB 的普通文件在后台读取和解码、后台保存；保存中继续输入会保留为下一次未保存修改。全部保存和退出前保存会等待写入完成，磁盘冲突和编码失败仍会提示。达到 1 MiB 的 JSON 预览与折叠在后台计算，连续输入会合并刷新，过期结果不会覆盖新内容；更新期间复制／导出／应用结果暂不可用。

JSON 左侧原样保留打开、输入和粘贴的文本，可以自由添加空行、缩进或输入未完成的 JSON，保存也保留这些内容。右侧按选定的 2 或 4 空格显示格式化结果，错误只作提示。主动编辑右侧时仍会同步到左侧。需要整体写回格式化或压缩结果时，点右栏底部的「应用到原文」。写回后可以撤销。

点「更多」中的转换，在右栏查看结果。再次点同一项即可取消预览并恢复双栏同步。去转义和键排序等结果可通过「应用到原文」写回。XML 和 Form-Data 可通过右栏底部的「在新标签打开结果」打开。「另存」可原样导出当前结果。「去转义」支持带或不带外层引号的转义文本，也可展开对象和数组里以字符串保存的 JSON。格式化后可在行号边折叠结构。JSON 和 Markdown 分屏都可切换同步滚动。进入「对比」后，两份 JSON 独立编辑。点「左侧操作」或「右侧操作」可展开菜单，对相应一栏格式化、压缩或转换。

Markdown 支持分屏预览。点击文档工具栏左侧的「展开大纲」，或按 Ctrl+Alt+B，可打开和收起左侧大纲。大纲顶部支持展开或折叠全部标题，点击任一标题即可跳转。HTML 支持编辑、分屏或完整预览，点「刷新预览」可重新渲染未保存的内容。网页中的 JavaScript、CSS 和相对资源按浏览器规则运行。依赖 HTTP 接口的页面可通过项目自己的开发服务运行。

## Office、PDF 和图片

打开 `.xlsx` 可编辑单元格、常用公式和格式。Ctrl+S 保存，Ctrl+Shift+S 另存为。旧格式 `.xls` 可先另存为 `.xlsx`。中文输入法选词完成后再保存。

公开下载版提供 DOCX 只读预览，支持正文、表格、内嵌图片和标题导航。包含 Word 组件的本地构建可编辑 `.docx` 的正文、段落、表格和图片，并支持保存及另存为。 [Word 组件许可说明](design.md#发布范围)

Word 和 PDF 顶部显示文件名，点击「−」「＋」缩放，点击百分比适合窗口宽度。点击「标题」可打开左侧标题列表，点击名称跳到对应位置。PDF 和本地 Word 编辑版支持展开或收起各级标题，Word 编辑时会更新列表。PDF 优先显示文档书签，没有书签时读取已标记的标题。PDF 支持翻页、查找和另存原件。Excel 编辑界面、Word 和 PDF 阅读区随当前窗口的主题切换，文件里的颜色会随内容保存。XMind 和图片在独立标签中只读查看。

在图片工具栏点「识别文字」。首次使用时点「下载并识别」，下载约 39.3 MiB，随后可离线识别简体中文和英文。可以在结果框选中文字按 Ctrl+C，也可以点「复制全文」。如要释放安装占用，在同一窗口点「移除 OCR 组件」。

也可以在图片工具栏点「AI 识图」，从已配置且支持图片输入的 API 模型中选择一个，再选择「提取文字」或「解读内容」。点「开始识图」才会把当前预览的图片发给弹窗标明的服务。AI 识图独立于本地 OCR，结果支持选中复制和复制全文。

## AI 助手、Git 和终端

工具侧栏可打开 AI 助手。先在「设置 → AI」里添加 API 服务或已登录的本机 CLI，再从输入框右下角选择模型和思考水平。使用已登录的 CLI 时，模型配置沿用该 CLI 的本机登录状态。API 密钥可在输入框内点眼睛显隐。发送时会使用输入框列出的上下文，点上下文标签的关闭按钮可将其移除。生成修改和新建草稿都可以先审阅再应用。拖选消息中的文字可复制选区，消息按钮可复制全文。聊天记录可从顶部时钟图标打开、重命名和删除，本地会保留对话。

通过项目菜单打开 Git 或 PowerShell 可直接定位到项目。Git 在侧栏展开，终端在底部展开，可以同时使用。Git 面板调用本机 Git for Windows。点击当前分支可切换本地分支，旁边的图标可创建并切换到新分支。切换后，打开的未修改文本会刷新，已有草稿会保留。终端使用 Windows PowerShell，Ctrl+Shift+C 复制，Ctrl+Shift+V 粘贴。

## 数据目录

默认在 EXE 所在文件夹下使用 `EditorX\data`。如果 EXE 已放在名为 `EditorX` 的文件夹中，直接使用该文件夹内的 `data`。升级时，如果新目录尚不存在且 EXE 同级有可识别的旧版数据，完全退出旧版后启动新版，会自动复制旧数据并保留原目录，便于回退。新目录已存在时优先使用新目录，两份目录不会合并。

在「设置 → 存储管理 → 应用数据」可以查看当前路径。点击「更换位置」选择空文件夹，再点击「迁移并重启」。显式选择的目录继续生效。环境变量 `VIVA_EDITOR_DATA_DIR` 优先于这些设置，可为独立实例指定目录。WebView2 缓存使用系统临时目录，退出时清理。

换电脑时，先在两边彻底退出 EditorX，再把「存储管理」显示的整个 `data` 文件夹复制到新电脑的默认位置。设置、模板、个人词库、草稿和本地历史可以带走。如果目标已有数据，先留一份备份，避免直接覆盖。项目、最近文件和本地历史保存原文件的绝对路径，项目文件须另外复制。路径变了就重新添加项目或打开文件。数据目录指向文件 `editorx-data-location.json` 保存本机位置，换电脑时只复制数据目录。

AI API 密钥和保密请求头使用 Windows 账户加密，通常需要在新电脑重新输入。启用主密码的密码本，可在新电脑用同一主密码解锁。未启用主密码时，可以先在旧电脑「密码本设置」启用主密码，再复制数据。也可以在旧电脑「导出加密备份」，复制数据时跳过原来的 `passwords.edxvault` 和 `password-vault-archives`，然后在新电脑首次打开密码本时用备份密码恢复。多台电脑各自维护数据，手动复制相当于迁移当时的副本，使用中的会话文件不适合多台同时写入。

## Git 差异、历史与冲突

一个项目文件夹可以包含多个 Git 仓库。EditorX 在后台查找各仓库，Git 面板可切换仓库，打开文件时可按文件所属仓库进入 Git。项目根目录包含多个仓库时，可在项目右键的 Git 菜单按仓库选择提交记录、暂存或提交范围。新增或移动仓库后，可刷新项目或 Git 状态重新查找。

Git 侧栏顶部切换「提交变更」「搁置」「贮藏」。仓库只在顶部选择，当前分支与获取、拉取、推送放在同一行，悬停分支可查看完整分支名和上游。变更树分为「更改」「未加入 Git」和冲突等分类，每个文件只出现一次。文件名下方显示所属目录，根目录文件标为「仓库根目录」，悬停可查看完整路径。状态使用「已删除」「已修改」「未跟踪」等说明。默认按目录分组，连续单子目录合并为一行；「分组与显示」可另行开启仓库和顶层模块层级或显示忽略文件。

Git 仓库从项目树中已添加的项目选择。单独打开文件时，可先添加项目再启用 Git。变更工具栏显示已勾选数量和可提交文件总数。复选框仅选择本次要提交的文件，不执行 Git 或改动暂存区，可以连续勾选文件、目录和整组，也可全选或取消全选。点击「提交」或「提交并推送」后，才提交这些文件的全部已保存改动，未选文件已有的暂存内容仍保留。文件不会因为已有部分暂存而自动勾选。需要只提交之前暂存的改动时，在提交按钮旁的下拉菜单选择「仅提交暂存区」。可填写多行说明，使用「复用提交说明」填入旧说明，也可勾选「修改上次提交」，读取进度显示在提交说明输入框内。

提交前会检查本次勾选且已打开的文件。如果还有未保存编辑，或磁盘内容和打开时的版本不同，请先保存、比对或重新读取。通过「仅提交暂存区」操作时，提交的是你已经明确暂存的版本。若本地分支缺少远程提交，或暂时无法确认远程状态，可以返回处理，也可以确认仅在本地提交。

勾选文件后，点击提交说明上方的 AI 图标生成说明。使用「设置 → AI」已保存的服务；有多个服务时可选择本次使用的服务。从 Git 打开 AI 设置时，可点「返回 Git 提交」回到原来的勾选和说明草稿。仅将勾选文件的已保存改动发送给该服务，未保存草稿请先保存。结果按界面语言生成并填入输入框，可继续编辑或按 Ctrl+Z 恢复原说明，不会自动提交或推送。生成时点击取消可停止；取消、失败、改选文件、切换仓库或关闭 Git 侧栏都保留原说明。

AI 提交说明一次最多选择 100 个文件，单文件不超过 8 MiB，发送的改动上下文不超过 96 KiB。超限时可缩小选择；链接和目录项不读取，二进制只提供状态信息。

「搁置」和「贮藏」可以暂时收起已写入磁盘的改动，包括未加入 Git 的文件。「应用」保留该记录，「弹出」在应用成功后移除记录。EditorX 的搁置条目随仓库的 Git stash 保存，也可在终端用 `git stash list` 查看。

Git 面板打开期间自动监听磁盘文件和 Git 元数据，外部提交、暂存或编辑后在后台更新状态，保留仍有效的勾选。点击顶部「提交记录」打开可移动和缩放的独立窗口，可按当前分支、所有分支、本地／远程分支和标签筛选，也可搜索提交说明或哈希，并按作者与时间缩小范围。列表分开展示提交说明、作者、时间和哈希，窄窗口使用两行避免重叠。右侧显示完整说明、引用和变更文件，点击文件才查看差异，可返回记录列表。每次加载 100 条，支持加载更多；搜索在 Git 历史中执行，不限于已加载页面。

项目树中的项目、目录和文件右键都有「Git」子菜单。可打开 Git 面板，也可按当前范围勾选提交、暂存、取消暂存或查看提交记录。文件还可以直接查看 Git 差异。目录操作只匹配该目录下的变更，勾选提交不会改变暂存区。

侧栏点击文件默认比较 HEAD 与磁盘内容，包含已暂存和未暂存改动，与整文件提交范围一致。文件右键「查看暂存区差异」「查看未暂存差异」分别进入原有分块暂存流程。未保存草稿请先保存；提交记录中的合并提交与第一父提交比较。

差异窗口支持循环切换区别、全文件与四行上下文视图。普通已跟踪文本修改可「暂存此块」或「取消暂存此块」，不会改动工作区文件；新增、删除、重命名文件使用整文件暂存。查看之后内容有变化时，刷新差异后再操作。

点冲突文件进入编辑器，通过「采用当前分支」「采用传入分支」「保留双方」逐块处理，也可手动编辑。每次选择可 Ctrl+Z 撤销；单块改动超过撤销容量时保留原文，改为分段编辑。检查结果后点「保存并标记已解决」；有剩余冲突标记或保存失败时不会暂存。删除／修改、二进制等非文本冲突仍需外部 Git 工具处理。

## 普通分屏和编辑导航

- 标签右键「在普通分屏中打开」，或 Ctrl+\ 开关普通分屏。左右文件下拉框可以切换已打开的普通文本，拖动中间边框调整宽度。可查看同一文件的两个位置；同文件视图共享内容、光标选区和撤销栈，滚动位置独立。关闭分屏不会关闭文件。
- 手动补全按 Alt+/，IntelliJ IDEA 和 PyCharm 预设按 Ctrl+Alt+Space。可在编辑区右键选「补全文档词 / 关键字」，也可在「设置 → 快捷键 → 分屏、补全与导航」修改绑定。↑／↓ 选择，Enter 或 Tab 接受，Esc 关闭。
- 「设置 → 编辑器 → 输入时自动补全」默认开启。输入两个或更多字符并停顿约 100 ms，会看到匹配当前词前缀的文档词或关键字。近处出现的文档词优先，同一词内继续输入或退格会更新候选。Tab 接受第一项，也可用 ↑／↓ 或 Page Up／Page Down 选择再按 Enter。直接按 Enter 正常换行。中文输入法提交文字后才提示，补全可用 Ctrl+Z 一次撤销。
- Go、Java、JavaScript 等代码支持括号块折叠；Python/YAML 按缩进，Markdown 按标题和围栏，XML/HTML 按成对标签。Ctrl+Shift+[ 折叠全部，Ctrl+Shift+] 展开全部。扫描为词法规则，超过 32 MiB 不扫描折叠。
- Alt+← / Alt+→ 返回或前进到先前的文件与位置。切换文件及跨八行以上的定位纳入记录，最多保留 100 个位置，仅当前窗口本次运行有效。
- Alt+Shift+方向键扩展矩形选区，也可继续用 Alt+拖动；输入、删除及粘贴复用多光标撤销。短行仍停在行尾，不补虚拟空格。

新增命令可在命令面板查找，并在「设置 → 快捷键」调整默认按键（键盘列选择保留固定 Alt+Shift+方向键）。普通分屏用于文本编辑，分页大文件和 Office 仍使用原有视图。
