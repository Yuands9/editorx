# EditorX 使用指南

## 打开文件和项目

下载 [Windows 版 EXE](https://github.com/Yuands9/editorx/releases/download/v0.32.9/EditorX-0.32.9.exe) 到有写入权限的目录，双击运行下载的 EXE。可以把文件拖入 EditorX 窗口打开，也可以拖到 EXE 图标上。文件夹拖入后作为项目添加。按 Ctrl+O 可以选择一个或多个文件。按 Ctrl+Shift+O 添加项目文件夹，点击左侧项目树里的文件即可打开。项目的「…」菜单支持打开资源管理器、打开 Git 或终端、刷新和移除项目。收起侧栏后，顶部仍可打开文件、添加项目和恢复侧栏。

在 Windows 上执行 `.\tools\register-open-with.ps1` 后，常见文件类型的「打开方式」里会显示 EditorX。文件右键菜单也有「使用 EditorX 打开」，无后缀文件可用这个入口。

点标签栏加号或双击空白处可新建标签。关闭最后一个标签后，中央会显示打开文件和最近文件入口。标签可拖动排序或通过右键菜单加入分组。双击标签名或组名可重命名，按 Enter 确认。单击组名展开或收起，拖组名可移动整组。固定的标签和分组可以直接关闭。批量关闭会跳过固定项。右键已保存的标签可打开文件所在目录。

在主菜单选择「打开链接文件」，或按 Ctrl+Shift+L，粘贴 HTTP 或 HTTPS 链接后回车。支持图片、PDF、Word（DOCX）、JSON、Markdown、JavaScript 等。单个链接文件最大 128 MiB，下载到本地数据目录。文本修改会保存到本地副本，也可另存到其他位置。打开链接的快捷键可在设置中修改。

## 设置

点击右下角齿轮或按 Ctrl+, 打开或关闭设置。左侧按外观、编辑器、备份、快捷键、AI 和关于排列，顶部可以搜索设置。选择会即时生效并自动保存。

「外观」提供跟随系统、深色和浅色。首次运行默认跟随 Windows 应用主题。右下角的主题按钮在深色和浅色之间直接切换。要恢复跟随系统，可在「外观」里选择。默认显示托盘图标。关闭单个窗口时，其他窗口继续打开。关闭最后一个窗口时，应用会保存会话并按设置退出或隐藏到后台。

「编辑器」可设置字体、字号、Tab 缩进、默认折行和 JSON 缩进，并提供实时预览。在「快捷键」中点击某项的按键，按下新的组合键或功能键即可改绑，也可清除绑定和恢复默认。AI 面板的「模型设置」可直达「AI」。填写模型配置后，点「保存配置」或按 Enter 保存。切换到其他设置分类时，表单会保留本次填写的内容。

在「备份」中点「导出备份」，勾选已打开的文件或草稿，再选择保存位置。备份会压缩成 ZIP，保留所选标签所属的分组和工作区项目。点击「选择备份…」打开 EditorX 导出的 ZIP 文件。恢复时可查看进度或取消，完成后会将备份的文件和草稿加入当前窗口，保留原有标签。升级后，旧版遗留的多窗口会话也会在启动时合并到一个窗口。

「关于」显示当前版本并可查询 GitHub 的最新公开版本。发现新版后，公开便携版可在弹窗下载并校验 EXE，点击「更新并重启」会先保存会话。含 Word 编辑的本机构建可从弹窗下载公开版。

点击托盘图标可恢复窗口。右键可打开设置或彻底退出。隐藏时也可双击原快捷方式或 `EditorX.exe` 恢复已有窗口，即使托盘图标关闭也可以。要主动添加一个工作窗口，使用 Ctrl+Shift+N。

## 编辑、查找和保存

编辑区支持 UTF-8 文本、UTF-8 BOM、LF 和 CRLF。文件类型默认按名称和后缀识别，点击右下角的类型可为当前标签手动选择语法。切回「自动识别」即可恢复默认行为。

Ctrl+F 打开查找浮窗，Ctrl+R 直接打开替换，按住标题栏可拖动。查找支持普通文本、转义字符、Go 正则、区分大小写和全词匹配。「查找全部已打开文档」按文件分组显示结果，点击结果可定位。Enter 或 Shift+Enter 找下一处或上一处，关闭浮窗后可继续用 F3 或 Shift+F3。

在查找或替换框中可直接粘贴多行文本，也可按 Ctrl+Enter 换行。转义字符模式接受 `\n`、`\r\n`、`\t` 和 `\\`。正则替换支持 `$1` 和命名分组引用。可以替换当前匹配、当前文件的全部匹配，或当前窗口所有已打开的可编辑文本标签。替换写入编辑缓冲，按 Ctrl+S 保存，批量替换可在各文件中撤销。

Ctrl+S 保存，Ctrl+Shift+S 另存为。保存时会核对原文件的磁盘状态。文件已被别的程序改动时，可另存为一份新文件以保留两份内容。关闭有修改的标签时，可以勾选「不再询问」。之后关闭标签会自动保存，未命名文件会弹出保存位置。可在「设置 → 外观 → 关闭标签时询问保存」中重新开启提示。关闭窗口时未保存草稿可随本地会话恢复。

在「设置 → 编辑器」可选择系统已安装的等宽字体和字号，设置 Tab 的列宽以及插入空格或 Tab 字符。在「默认自动折行」中勾选要开启折行的文件类型，新设置默认只勾选 JSON。标签手动选择的折行和 JSON 缩进优先于全局默认值。

## JSON 和预览

JSON 工作区两栏按设置页选定的 2 或 4 空格缩进格式化，并可自动折行显示，两边都能编辑和复制。常规编辑时任一栏的修改会同步到另一栏，输入暂未完成时也会保留正在编辑的内容。Ctrl+S 保存当前文件。

点「更多」中的转换，在右栏查看结果。再次点同一项即可取消预览并恢复双栏同步。右栏菜单会标出当前模式。去转义和键排序等结果可通过「应用到原文」写回。XML 和 Form-Data 可在新标签打开。「另存」可原样导出当前结果。「去转义」支持带或不带外层引号的转义文本，也可展开对象和数组里以字符串保存的 JSON。格式化后可在行号边折叠结构。JSON 和 Markdown 分屏都可切换同步滚动，「对比」中的两份 JSON 独立编辑。

Markdown 支持分屏预览。点击文档工具栏左侧的「展开大纲」，或按 Ctrl+Alt+B，可打开和收起左侧大纲。大纲顶部支持展开或折叠全部标题，点击任一标题即可跳转。HTML 支持编辑、分屏或完整预览，点「刷新预览」可重新渲染未保存的内容。网页中的 JavaScript、CSS 和相对资源按浏览器规则运行。依赖 HTTP 接口的页面可通过项目自己的开发服务运行。

## Office、PDF 和图片

打开 `.xlsx` 可编辑单元格、常用公式和格式。Ctrl+S 保存，Ctrl+Shift+S 另存为。旧格式 `.xls` 可先另存为 `.xlsx`。中文输入法选词完成后再保存。

公开下载版提供 DOCX 只读预览，支持正文、表格、内嵌图片和标题导航。包含 Word 组件的本地构建可编辑 `.docx` 的正文、段落、表格和图片，并支持保存及另存为。 [Word 组件许可说明](design.md#发布范围)

Word 和 PDF 顶部显示文件名，点击「−」「＋」缩放，点击百分比适合窗口宽度。点击「标题」可打开左侧标题列表，点击名称跳到对应位置。PDF 和本地 Word 编辑版支持展开或收起各级标题，Word 编辑时会更新列表。PDF 优先显示文档书签，没有书签时读取已标记的标题。PDF 支持翻页、查找和另存原件。Excel 编辑界面、Word 和 PDF 阅读区随当前窗口的主题切换，文件里的颜色会随内容保存。XMind 和图片在独立标签中只读查看。

## AI 助手、Git 和终端

右侧工具栏可打开 AI 助手。先在「设置 → AI 助手」里添加 API 服务或已登录的本机 CLI，再从输入框右下角选择模型和思考水平。使用已登录的 CLI 时，模型配置沿用该 CLI 的本机登录状态。API 密钥可在输入框内点眼睛显隐。发送时会使用输入框列出的上下文，点上下文标签的关闭按钮可将其移除。生成修改和新建草稿都可以先审阅再应用。拖选消息中的文字可复制选区，消息按钮可复制全文。聊天记录可从顶部时钟图标打开、重命名和删除，本地会保留对话。

通过项目菜单打开 Git 或 PowerShell 可直接定位到项目。Git 面板使用本机 Git for Windows。暂存文件并输入提交说明后，点击提交图标或按 Enter。获取、拉取和推送图标旁的提示会显示对应操作。终端使用 Windows PowerShell，Ctrl+Shift+C 复制，Ctrl+Shift+V 粘贴。

## 常用快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 新文件 / 新窗口 | Ctrl+N / Ctrl+Shift+N |
| 打开链接文件 | Ctrl+Shift+L |
| 打开文件 / 添加项目 | Ctrl+O / Ctrl+Shift+O |
| 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S |
| 关闭当前标签 | Ctrl+W |
| 下一个 / 上一个标签 | Ctrl+Tab / Ctrl+Shift+Tab |
| 文件栏 / Markdown 大纲 | Ctrl+B / Ctrl+Alt+B |
| 自动折行 | Alt+Z |
| 查找 / 替换 | Ctrl+F / Ctrl+R |
| Git / 终端 | Ctrl+Shift+G / Ctrl+Alt+T |

默认数据目录为 EXE 同目录的 `data`。其中包含会话、草稿、最近文件和 AI 设置。可通过环境变量 `VIVA_EDITOR_DATA_DIR` 为独立实例指定其他目录。
