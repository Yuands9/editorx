# EditorX 使用指南

在 Windows 上打开、查看和编辑多种格式的本地文件。

## 文件与标签

- 打开文件夹，在左侧浏览目录。Ctrl+B 完全关闭侧栏，从顶部图标恢复。
- 点击标签切换文件；每份文档保留自己的编辑状态。
- 钉住常用文件，双击标签栏空白处新建文档。

## JSON 工具

左侧编辑原文，右侧查看或编辑处理结果。两栏都可复制，粘贴完整 JSON 对象或数组时会自动缩进。

| 操作 | 用途 |
| --- | --- |
| 格式化 | 展开层级，选择 2 / 4 空格，保留键顺序 |
| 键排序 | 递归排列对象键，保留数组顺序 |
| 压缩 | 去掉不必要的空白 |
| 转 XML | 生成保留类型的 XML |
| 对比 | 载入另一份 JSON，查看差异高亮并点击路径定位 |
| 更多 | Form-Data、转义/去转义、Unicode 编码/解码 |

右侧草稿可以复制、另存，也可以点击「应用」写入原文。XML 和 Form-Data 应用后会新建标签。压缩保持单行，可以在结果区开启软折行。JSON 错误可直接跳到原文位置。

### 配置示例

~~~json
{
    "name": "中文项目",
    "enabled": true,
    "tabWidth": 4
}
~~~

## Markdown

选择 **编辑**、**分屏** 或 **预览**。
在工具栏左侧打开大纲，可以展开或折叠全部标题，点击标题即可定位到相应章节。

### 快捷键

`Ctrl+O` 打开文件，`Ctrl+S` 保存，`Ctrl+W` 关闭当前标签。

> 未保存的内容会在关闭时询问是否保留。
